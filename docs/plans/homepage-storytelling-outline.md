# Homepage storytelling outline

Source of truth for how the homepage tells Scorecard's story. Designs: Paper file "scorecard app" → page "website - home" → board "jz v2". HTML mock: `mockups/home-v15.html`.

## What Scorecard is (one paragraph)

Scorecard is a prospecting tool for people who sell to, or buy, small and mid-sized businesses. You describe the businesses you want in plain words. Agents search an index of every business in the US, read each one's website and public records, answer the questions you care about with sources, and score every company for fit. You get a short, ranked list with the reasons, and your people do the outreach. Buyers: B2B sales teams, founders who still sell, and acquisition searchers (search funds, PE).

## The core idea

A database tells you who exists. The scarce thing is attention: rep time, or a searcher's runway. Scorecard spends research so you can spend attention only where it fits, and it shows its work.

## The three agent sections

Each answers one question the visitor already has, and ends on one picture they could describe to a colleague. The example business is interchangeable; what matters is the pattern below.

| | Search | Signals | Score |
|---|---|---|---|
| Visitor's question | Can it find the specific businesses I sell to? | Why should I trust what it found? | Who do I call first? |
| Agent | Search agent | Research agent | Scoring agent (coming soon) |
| Pattern | Plain-words ask → large pool → agent reads each one → a short list, each with its proof | A business → several sources → each source becomes one answer with its source | Today's ranking → you mark a few → it learns the pattern → the rest re-rank, with reasons |
| Takeaway | Search by details, not industry codes. | Every answer shows its source. | Your judgment, applied to every account. |

## Rules
- Use one example across the three agent sections so it reads as one story; swap examples per audience if needed.
- Agents research; people do the outreach. Name the agent in a dark pill with the Scorecard dot mark.
- Circles mean data. Blue is grades and matches. Coral is for the action and hand notes only.
- Each agent section is a sticky scroll, about 4 keyframes, ending on the still picture.
- Plain, numerate copy. Lead with counts. No hype words.
