# Scorecard homepage v16 review

## Top 5 problems

1. **The agent is a footnote.** The map, histogram and bars appear to operate themselves. Put a named agent inside each scene, visibly checking businesses, extracting evidence and applying your priorities.
2. **Signals promises proof and supplies none.** Replace the histogram with Sierra Line and two source excerpts that visibly become answers. Leave one source attached in the final frame. Preserve an explicit “No evidence found” answer.
3. **The three stages repeat ranking instead of explaining different work.** Search already finds 38 “best” fits; Signals sorts weaker to stronger; Score ranks again. End Search with 412 qualifying matches. Research establishes facts. Score applies the visitor's stated priorities and decides who comes first. Show where those priorities came from.
4. **The animation asks too much attention for too little information.** CSS reserves 420vh per agent section, 12.6 viewport heights total,. Remove the compulsory scroll runway. Give each section a readable final composition with an optional replay; retain the sequence without requiring visitors to scrub twelve frames. Reduced motion currently removes transitions, not the runway.
5. **The page overstates what the pictures establish.** “Won't buy” implies purchase prediction; the hero's contact row promotes paid contact data beside a free CTA; “Your CRM” suggests integration; precise counts look measured. Sell fit, disclose trial limits, say CSV, and label invented examples. Explain credit consumption with a verified worked example.

## TAM/SAM

Place “Size this market” as an optional Search variant, after the core matching story. Show counts of businesses, with explicit criteria and coverage date. The US database is the search universe, not TAM. TAM is all qualifying businesses nationally; SAM adds the territory and service constraints the user can actually serve. Keep best-fit ranking out of this calculation. Do not imply revenue TAM without an explicit revenue-per-account assumption.

**Keyframes:** 1. Define the customer in plain words. 2. Agent counts qualifying US businesses, labeled TAM. 3. User selects serviceable states and segments; agent counts the subset, labeled SAM. 4. Hold nested outlines showing both counts and criteria, with “Research these businesses” leading into Signals. Use illustrative placeholders until counts are verified.
